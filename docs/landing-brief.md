# Landing Page Design + UI Agent Brief (founder's brief, verbatim)

We need to launch a high-end, visually distinctive landing page UI for our product.
The goal is NOT to create a generic SaaS/AI landing page. The website should feel designed, intentional, immersive, expressive, and memorable, with a strong visual identity from the first second.

## 1. Core Creative Direction
Take inspiration from the visual confidence and interaction quality of Sarvam, but do NOT copy its design.
Also incorporate our existing staggered character animation logo as a major part of the visual identity.
The overall direction should lean toward:

* Maximalism rather than minimalism
* Strong typography
* Layered compositions
* Interesting spatial relationships
* Editorial/art-directed layouts
* Unexpected but intentional interactions
* Rich motion
* Depth and visual hierarchy
* Micro-interactions throughout the page
* A strong sense of brand personality

The page should feel like a premium digital experience, not a template.
Avoid anything that looks like:

* Generic AI startup landing pages
* Generic "AI auditorial" aesthetics
* Standard centered hero + gradient background
* Floating glassmorphism cards everywhere
* Random blobs
* Excessive rounded rectangles
* Generic purple/blue AI gradients
* Stock illustrations
* Template-like feature grids
* "Trusted by..." sections that feel copied from every other startup
* Overuse of massive empty whitespace without a design purpose

Every visual element should have a reason to exist.

## 2. Hero Section
The hero should immediately establish the product's personality.
Do NOT simply create: "The future of X" / subtitle / CTA / screenshot.
Instead, design a visual experience around the product.
Explore ideas such as:

* The staggered-character logo animation becoming part of the hero
* Typography that responds subtly to cursor movement
* Text appearing character-by-character or through controlled staggered motion
* Layered typography
* Elements entering from different depths
* Interactive product fragments
* Subtle environmental motion
* A visual system that reacts as the user moves through the page

The hero should have strong composition, not just content centered on the screen.
The first viewport should answer:

1. What is this?
2. Why should I care?
3. What makes this product different?
4. What does the brand feel like?

## 3. Motion Design
Motion is a core part of the experience. Design a motion system, not random animations.
Define:

Entrance animations. Use carefully choreographed:
* Staggered character reveals
* Mask reveals
* Clip-path transitions
* Position + opacity combinations
* Scale transitions
* Layered entrances
* Scroll-triggered reveals

Hover interactions. Consider:
* Magnetic buttons
* Cursor-following elements
* Text displacement
* Image distortion
* Interactive typography
* Dynamic underlines
* Subtle scale/depth changes
* Cards that respond to cursor position

Scroll interactions. The page should feel alive while scrolling. Explore:
* Parallax layers
* Sticky storytelling sections
* Horizontal scrolling moments
* Text transformations
* Elements changing scale while entering the viewport
* Sections transitioning into each other
* Typography that changes weight/size/position
* Progressive visual reveals
* Background transitions

Do NOT animate everything. Motion should establish hierarchy and storytelling.
Use: fast, energetic motion for interactions; smooth, cinematic motion for section transitions; small micro-interactions for secondary elements.
Animations should feel intentional and performant.

## 4. Interactive Product Demonstration
Instead of relying entirely on screenshots, create interactive representations of the product:
* Interactive UI fragments
* Simulated workflows
* Hoverable data
* Expandable components
* Before/after interactions
* Cursor-driven demonstrations
* Small live-feeling product experiences

The user should feel like they are experiencing the product, not reading a marketing page about it.

## 5. Page Structure
Create a strong narrative flow. A possible structure:
Hero (brand + product + primary CTA) → Product Introduction (explain the problem through an interesting visual composition) → Product Experience (show the product in action) → Core Capabilities (NOT a boring 3x3 feature-card grid; instead large editorial sections, asymmetric layouts, interactive cards, scroll-driven storytelling, layered UI, typography-led sections) → Deep Dive (show how the product actually works: diagrams, UI fragments, animations, progressive disclosure rather than paragraphs of marketing copy) → Proof / Trust (present in a visually interesting way, avoid the standard logo wall) → Final CTA (a strong visual conclusion rather than repeating the hero) → Footer (part of the experience, not an afterthought).

## 6. Footer Design
Design a distinctive footer: oversized typography, large animated logo, navigation integrated into the composition, interactive hover states, subtle movement, brand statement, social links, contact/CTA, small utility navigation.
The footer can become one of the strongest visual moments on the page: the staggered character logo animation could return here, creating a visual bookend to the experience.

## 7. Typography
Typography should be a major design element, not merely content.
Experiment with: dramatic scale differences, large display typography, variable font weights, tight/expanded tracking, text cropping, overlapping type, editorial layouts, kinetic typography, text that reacts subtly to scrolling.
Establish a clear typography hierarchy. Typography should make the site recognizable even without the logo.

## 8. Visual System
Create a cohesive visual language before designing every section.
Define: primary typeface, display typeface if appropriate, body typeface, font scale, spacing system, grid, border treatment, radius system, shadows, background treatments, icon style, image treatment, motion curves, animation durations.
Avoid adding visual effects simply because they look impressive in isolation. The system must remain coherent.

## 9. Maximalism Without Chaos
The design should be maximalist, but controlled. Use visual density intentionally.
Think: layering + contrast + typography + motion + composition, rather than more gradients + more cards + more effects.
There should still be clear hierarchy. The eye should know where to look first, second, and third.

## 10. Interaction Details
Add small moments that make the interface feel crafted: buttons with meaningful hover transformations, navigation that reacts to scrolling, cursor interactions where appropriate, text reveals, image movement, section transitions, animated counters, expandable information, interactive diagrams, progress indicators, scroll position feedback, loading states, subtle sound-inspired visual rhythms without requiring sound.
These details should reward exploration.

## 11. Responsive Design
Do not simply shrink the desktop layout. Design separate compositions for desktop, tablet, and mobile. Preserve the visual identity and storytelling on smaller screens. Motion should also be adapted for mobile performance and usability.

## 12. Performance
Despite the visual ambition, the implementation must remain fast.
Prioritize: GPU-friendly animations, transform/opacity-based motion, lazy-loaded media, optimized images, avoiding unnecessary JavaScript animation loops, respecting `prefers-reduced-motion`, avoiding excessive WebGL unless it genuinely improves the experience.
The page should feel rich, not slow.

## 13. Competitive / Reference Research
Before designing, study high-quality digital experiences from: Sarvam, award-winning product websites, strong editorial websites, experimental interaction design, premium technology brands, sites recognized for exceptional motion and storytelling.
Study specifically: hero composition, typography, navigation, scroll behavior, section transitions, motion language, footer design, interaction patterns, information hierarchy, how they avoid looking like templates.
Use these references to derive design principles, not to copy layouts.

## 14. What I Want From the UI Agent
Do not jump directly into producing a generic landing page. First establish the creative direction.
Determine: overall art direction, visual language, typography strategy, grid/composition strategy, motion language, hero concept, scroll storytelling, interactive elements, footer concept, responsive behavior, component system, performance strategy. Then implement the page.
For every major section, explain internally through the design decisions: Why does this section look this way? Why does it move this way? What interaction is the user supposed to discover? How does it reinforce the brand?
The final result should feel like a carefully art-directed digital product experience, not something generated from a landing-page template.

**Most important constraint**: If the first design could plausibly be mistaken for a random modern AI/SaaS startup website, reject it and redesign it. We want people to recognize that this is our product before they even read all the copy.

Target feeling: beautiful + expressive + immersive + intelligent + slightly unexpected + highly polished.
Not: generic + safe + corporate + gradient + card grid.
